# DM-Program
This is a python program to help when running table-top games such as DnD 2024.

The program has the following functionality:
- open and save files
- keep track of the current turns
- keep track of player stats (hp, temp hp, conditions, etc as well as other basic stats, abilities, feats, etc)
- display a character sheet of the character with the current turn
- allow characters/monsters to be added or removed from the current game. Characters and monsters are stored in xml files
- allows new characters/monsters to be added and removed from the xml files
- allows characters/monsters to be modified that are within the xml files
- allows new character/monster sxml files to be generated
